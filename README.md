# КБЖВ v85 — верхній відступ і обрізання порожніх зон великих модальних вікон

**Основа:** v84. **Cloudflare Worker:** v80, без змін.

Змінено виключно стилі великих вікон «Додати продукт», «Редагувати продукт», «Видалити продукт» та «Змінити розташування» у мобільному viewport до 768px:

- Вміст починається під верхньою safe area (`env(safe-area-inset-top) + 12px`), не заходить під Dynamic Island iPhone 14 Pro.
- Максимальна висота картки — лише доступна висота області після верхнього/нижнього відступу. Внутрішній вміст прокручується, кнопки залишаються досяжними.
- `overscroll-behavior-y: none` замість `contain` для зазначених карток: у підтримуваних версіях Safari запобігає пружному порожньому простору над заголовком і під кнопками.
- При кожному відкритті цих чотирьох довгих вікон внутрішня прокрутка повертається до заголовка (вже відкриту форму не скидає).
- Розміри та центрування невеликих вікон «Сортувати», «Експорт», «Швидкі ваги» не змінено.

Не змінювалися збереження даних, калькулятор, швидкі ваги, логін, експорт, імпорт, API або Worker. У `script.js` оновлено напис v84→v85 та додано скидання прокрутки на початок тільки при відкритті чотирьох довгих форм. У `index.html` та `sw.js` оновлено адреси ресурсів і кеш `kbjv-pwa-v85`.

**Для оновлення GitHub Pages:** замінити `index.html`, `style.css`, `script.js`, `sw.js`. `manifest.webmanifest`, іконки та Worker не змінювати. Перезапустити PWA після оновлення кешу.

**Зауваження:** фізична перевірка на iPhone 14 Pro залишається потрібною. Специфічний для iOS ефект overscroll неможливо остаточно підтвердити браузером Chromium.
