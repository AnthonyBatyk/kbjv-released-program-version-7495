# КБЖВ v84 — прибирання чорної смуги під модальними вікнами (iPhone)

**База:** робоча версія v83. **Worker:** v80, без змін.

Причина: старий CSS додавав до кожного модального вікна псевдоелемент `.product-modal::after` — другий шар чорного затемнення, накладений на нижню область `env(safe-area-inset-bottom)`. Він створював неприродно чорну смугу знизу, особливо в установленій PWA на iPhone 14 Pro.

**Зміна:** прибрано лише цей додатковий нижній чорний псевдоелемент. Збережено основний напівпрозорий фон `.product-modal`, відступ для safe area, висоту модального вікна та повністю незмінний механізм фіксації фону і масштабування v83. У `script.js` змінено тільки текст версії. Не змінено операційні функції та їхню обробку.

Для переходу з v83 на v84 замінити в GitHub Pages: `index.html`, `script.js`, `style.css`, `sw.js`. Не замінювати `manifest.webmanifest`, PNG-іконки та Cloudflare Worker v80.

**Перевірка:** статична перевірка структури/синтаксису й браузерні тестування в Chromium. На реальному WebKit/iPhone перевірити нижню safe area після завантаження нової версії та перезапуску встановленої PWA; можливі платформні обмеження малювання в системній області.
