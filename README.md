# КБЖВ v86 — всі модальні вікна + підтвердження видалення фото

Основа: робоча версія **v85**. Cloudflare Worker: **v80**, без змін.

## Що змінено

1. **Усі 19 модальних вікон** використовують спільне правило для iPhone: верхній відступ з урахуванням `safe-area-inset-top` (Dynamic Island), нижній відступ з урахуванням `safe-area-inset-bottom`, обмежена доступною висотою картка й внутрішня прокрутка без зайвих порожніх зон. Короткі вікна залишаються по центру, високі автоматично вирівнюються зверху, зокрема імпорт, експорт, великі склади архіву та вікна адміністратора. Попередні виправлення для чотирьох форм продуктів не прибрано.
2. **При повторному відкритті** кожна модалка показує початок вмісту, а не останню позицію прокрутки. Вміст уже відкритого вікна не скидається.
3. **Видалення фото профілю:** з'являється системне підтвердження «Ви справді бажаєте видалити фото профілю?» з кнопками OK/Скасувати. При скасуванні дані та фото залишаються без змін. При OK виконується раніше наявний код видалення.
4. **Версія та PWA-кеш:** оновлено до v86 без зміни формату даних або Worker.

Не змінено логіку авторизації, PBKDF2, синхронізації, калькулятора, експорту/імпорту, створення та редагування продуктів. CSS додає лише загальні мобільні стилі; JavaScript — поведінку модалок і підтвердження видалення аватара.

## Оновлення на GitHub Pages

Замінити **4 файли**: `index.html`, `style.css`, `script.js`, `sw.js`. Іконки, `manifest.webmanifest` і Cloudflare Worker залишити незмінними.

## Зауваження

Перевірки в Chromium з мобільною емуляцією не замінюють фізичного тестування iOS Safari / PWA на iPhone 14 Pro.
