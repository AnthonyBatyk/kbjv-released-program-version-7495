# КБЖВ v82 — усунення сірої смуги внизу модального вікна на iPhone

Базова версія: **стабільний v81**, без перероблення її логіки.

## Зміни

- Установлено однаковий темний колір фону документа та нижньої safe area, **лише коли відкрито модальне вікно у встановленому iOS PWA**. Це прибирає різкий перехід від чорного затемнення до сірої смуги знизу, показаний на скриншоті.
- Для модального фону в установленому iOS PWA повернуто надійне розтягування від `top:0` до `bottom:0` без примусового `height:100dvh` (оскільки `100dvh` може виявитися коротшим за фактичний viewport). Висота прокручуваного **вмісту** вікна, фіксація фонового екрана та розташування кнопок **не змінені**.
- Стилі інших платформ, а також звичайний стан сторінки після закриття модального вікна не змінені.
- Змінено номер фронтенду на v82 та кеш PWA для доставляння нової версії.

## Оновлення GitHub Pages

Замінити **тільки 4 файли** у корені репозиторію: `index.html`, `script.js`, `style.css`, `sw.js`.

**Не замінювати** `manifest.webmanifest`, `icon.png`, `icon-192.png`, `icon-512.png`.
**Cloudflare Worker v80 не змінювати.**

Перед оновленням радимо експортувати копію даних. Після публікації перезапустити встановлений PWA на iPhone, щоб сервіс-воркер отримав новий кеш.

## Примітка до перевірки

Джерело дефекту — відмінність малювання нижньої системної ділянки viewport у standalone WebKit. Точну поведінку фізичного iPhone 14 Pro неможливо підтвердити Chromium: після оновлення перевірити вікна «Перевірка експорту», «Швидкі ваги» та головні вкладки на телефоні.
