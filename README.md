# КБЖВ v83 — виправлення чорної ділянки та обрізання модальних вікон на iPhone

База: v82. Незмінні: авторизація, синхронізація, база, експорт/імпорт, калькулятор, швидкі ваги, Cloudflare Worker.

Причина: після фіксації `body` через `position: fixed` з від’ємним `top` у мобільному WebKit фіксовані модальні вікна можуть зміщуватися на позицію попередньої прокрутки. На знімку зверху обрізаний заголовок форми, а знизу — її вміст. Фарбування нижньої ділянки у v82 лише приховувало колір, не усувало зсув.

Виправлення: фіксується лише `#main-app`, але не `body`, оскільки модальні вікна — прямі нащадки `body` і мають залишатися закріпленими на viewport. Під час закриття повертається початкова позиція прокрутки. Прибрано тимчасове чорне зафарбовування з v82. Залишено правила 16px для мобільних полів вводу.

Заміна у GitHub Pages: **index.html, script.js, style.css, sw.js**. **Worker v80, manifest.webmanifest, icon*.png — без змін.**

Після оновлення встановленого PWA на iPhone перевірити модалки зі сторінки, прокрученої вниз, зокрема редагування, додавання продукту, сортування, швидкі ваги, імпорт/експорт. Перевірено у Chromium; поведінку фізичного iPhone/WebKit остаточно перевірити на пристрої.
