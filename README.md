# КБЖВ — v81 (мобільний масштаб і фіксація модальних вікон)

Це оновлення фронтенду на основі стабільного `kbjv_pwa_v80`. Не змінено дані користувачів, авторизацію, розрахунки, продукти, імпорт/експорт та логіку Cloudflare Worker.

## Що змінено

1. **Прибрано збільшення сторінки на iPhone/iPad під час введення**: для полів пошуку, швидких ваг (усі 4 поля), додавання і редагування продуктів, калькулятора, архіву, статистики, профілю й авторизації використовується мінімальний розмір шрифту 16 px у мобільному/сенсорному режимі. У v80 спеціальне правило для швидких ваг задавало 14 px і перекривало попередній захист.
2. **Зафіксовано масштаб** через viewport (`minimum-scale=1`, `maximum-scale=1`, `user-scalable=no`) і запобігання масштабуванню подвійним дотиком на елементах керування. Браузери можуть дозволяти спеціальні системні функції збільшення для доступності, що не контролюються PWA.
3. **Збережено місце сторінки під модальними вікнами**: узгоджено блокування фону з відновленням горизонтального/вертикального прокручування після закриття, включно з випадками кількох відкритих вікон. Прокрутка **всередині** довгих форм залишається доступною.
4. Оновлено показ номера фронтенду до v81 та кеш Service Worker до `kbjv-pwa-v81`, щоб пристрої отримали актуальні CSS/JS.

## Розгортання

- Зробіть резервну копію даних через наявний експорт, перш ніж оновлювати застосунок.
- Замість файлів v80 у **корені** репозиторію GitHub Pages розмістіть файли з папки `kbjv_pwa_v81` цього архіву (`index.html`, `style.css`, `script.js`, `sw.js`, іконки тощо).
- Cloudflare Worker **не оновлювати**: `kbjv_worker_v80` сумісний із фронтендом v81. Не змінювати PBKDF2, D1 або секрети.
- Відкрийте сайт з інтернетом і використайте кнопку «Оновити сайт» або повністю закрийте й знову відкрийте PWA після перевстановлення кешу.
- В інформації про сайт версія фронтенду — **v81**, Worker лишається **v80**, це очікувано.

## Межі перевірки

Перевірку коду й сценарії на тестовому браузері описано у `ПЕРЕВІРКА_v81.md`. Автоматизоване тестування браузером Chromium не гарантує ідентичної поведінки мобільного Safari: фокус клавіатури та системні жести слід перевірити на фактичному iPhone.

Попередня документація v80 залишена як `README_v80_база.md`, а її попередній звіт — як `ПЕРЕВІРКА_v80_база.md`.
